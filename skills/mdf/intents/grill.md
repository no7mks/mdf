# Grill

## 决策树

```text
议题
├─ 缺失 → 仅显示用法
└─ 存在 → 建树 → 逐轮解决可判定分支 → 用户确认共同理解
```

## 工作流（唯一执行契约）

1. **约束**；要求非空议题；证据：用户提供的议题；通过 → 2；失败 → 仅显示用法。
2. **约束**；展示简明的决策树、已确认项、待决分支、依赖和预计总题量；
   证据：当前决策树；通过 → 3；失败 → 将缺失信息列为待决分支并继续澄清。
3. **约束**；持续、深入地追问，每轮只询问前置依赖已解决且彼此独立的问题；每题给建议答案，
   并以 `当前题号/总题量` 标记；一轮可包含多个问题；证据：该轮问题集；通过 → 4；
   失败 → 回到 2 重组问题。
4. **约束**；等待用户答复整轮，文件系统或工具可查证的事实自行查证，取舍交给用户；
   证据：答复与查证结果；通过 → 5；失败 → 等待答复。
5. **约束**；更新树；题量变化时先报告修订总数；证据：更新后的树；
   通过 → 未决分支回到 3，全部解决时 6；失败 → 将矛盾列为待决分支，回到 3 澄清。
6. **约束**；取得用户对共同理解的确认；证据：明确确认；通过 → 结束；
   失败 → 不要据此采取行动，回到 3。
