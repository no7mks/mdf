# 文档结构规则

适用于 MDF 管理的全部 Markdown：根文档、`docs/**`（`docs/JOTS.md` 除外）、`AGENTS.md`
托管区块，以及 MDF 自身的 Skill 与模板。修复方向是结构化，不是压缩措辞或删减信息。

**机械限制**：硬限制由 CLI `fact-audit` 报 `prose.*` finding，软限制由审阅判断。

| code | 度量 | 软限制 | 硬限制 |
| --- | --- | --- | --- |
| `prose.block` | 连续散文物理行（不含列表、表格、代码、标题） | 3 | 6 |
| `prose.sentence` | 单句显示宽度（按 `。；！？` 切分，链接只计文字） | 80 | 120 |
| `prose.list_item` | 单个列表项含续行的物理行 | 2 | 4 |
| `prose.section` | 一个标题下的散文行合计 | 8 | 15 |
| `prose.emoji` | 允许集合外的 emoji | — | 0 |

**内容形态**（审阅）：

| 内容 | 写成 |
| --- | --- |
| 并列 3 项以上 | 列表 |
| 两个以上条件分支 | 表格或决策树 |
| 3 步以上有序流程 | 编号列表或图 |
| 多个对象 × 多个属性 | 表格 |
| 规则带例外或细节 | 主规则一级列表，例外与细节放二级 |

- 每节开头用一句话说明本节解决什么。
- emoji 只用 ⚠️ 易错与警告、✅ 允许、❌ 禁止、💡 提示、📌 关键约束。
  - 只作行首标记，可跟在列表符号之后。
  - ❌ 不用在标题、表头与代码中，不作装饰。
