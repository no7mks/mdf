# 文档结构规则

本规则规定 MDF 的文档结构与说明性输出；改写保留信息与语义。

- 目标仓库：根文档、`docs/**`（`docs/JOTS.md` 除外）与 `AGENTS.md` 托管区块。
- MDF 自身：Skill、intent、模板、`docs/` 与根文档。
- 说明性输出：现有 intent 的文字、图解与交互 HTML；按需生成，不新增入口。

## Markdown 结构

本节规定全部受管 Markdown 的机械限制与内容形态；修复采用结构化，不删减信息。

**机械限制**：硬限制由 CLI `fact-audit` 报 `prose.*` finding。
软限制必须改到符合，不得当作可忽略建议。

| code | 度量 | 软限制 | 硬限制 |
| --- | --- | --- | --- |
| `prose.block` | 连续散文物理行（不含列表、表格、代码、标题） | 3 | 6 |
| `prose.sentence` | 单句显示宽度（按 `。；！？` 切分，链接只计文字） | 80 | 120 |
| `prose.list_item` | 单个列表项含续行的物理行 | 2 | 4 |
| `prose.section` | 一个标题下的散文行合计 | 8 | 15 |
| `prose.emoji` | 允许集合外的 emoji | — | 0 |

**内容形态**（必须按表组织，不是建议）：

| 内容 | 必须写成 |
| --- | --- |
| 并列 3 项以上 | 列表 |
| 两个以上条件分支 | 表格或决策树 |
| 3 步以上有序流程 | 编号列表或图 |
| 多个对象 × 多个属性 | 表格 |
| 规则带例外或细节 | 主规则一级列表，例外与细节放二级 |

- 每节开头必须用一句话说明本节解决什么。
- emoji 只用 ⚠️ 易错与警告、✅ 允许、❌ 禁止、💡 提示、📌 关键约束、
  📂 工作区目录、📍 当前分支、⬇️ 工作区切换。
  - 只作行首标记，可跟在列表符号之后。
  - ⬇️ 只作为切换横幅的中间一行，不作文内标记。
  - ❌ 不用在标题、表头与代码中，不作装饰。

## 文字与语义

本节借鉴 ASD-STE100 的清晰原则，帮助读者判断执行条件、动作与结果。

- 同一概念使用同一术语；名称以项目词典、契约或标识符为准。
- 明确执行者、动作和对象；把读者必须先知道的条件放在动作之前。
- 一个步骤表达一个主要动作；顺序动作拆步，同时动作明确写出同时发生。
- 改写保留规则强度、否定、例外、数值、路径、命令、链接及未验证状态。
  - 不合并 `fixed` 与 `closed`，不把已执行改成已通过，不把建议改成必须。
- 保留简体中文与现有 English technical terms；不引入受控英文词典、合规分数或中文词数硬限制。
- 语义复核由 Agent 对照原文与 evidence 执行；机械检查不能替代语义判断。
  - 规则有歧义且改写需要取舍时，先询问用户；不得自行增删行为契约。
- 原则来源：[ASD-STE100 官方 FAQ](https://www.asd-ste100.org/STE_faq.html)。
  - 借鉴写法不代表符合完整标准；不按模型记忆宣称合规。

## 选择解释载体

本节按读者的问题选择载体，已有结构足够清楚时不重复制作产物。

| 读者需要 | 载体 |
| --- | --- |
| 查规则、条件或具体动作 | 简明文字、编号步骤 |
| 比较多个对象或方案 | 表格 |
| 看依赖、关系或条件分支 | 图解，辅以必要的文字说明 |
| 改变条件并观察结果 | 用户明确需要交互讲解时生成 HTML |

- 普通 Markdown 与聊天关系图使用 Mermaid；宿主不支持时用 Unicode。
  - intent 文档保留 Unicode 决策树与唯一工作流表；辅助图解不成为第二份执行契约。
- 图中标明条件、箭头方向、失败出口与必要回路，逐条核对来源。
- 区分当前事实、示例假设和未核实项；关键结论、箭头与交互结果提供来源链接。
  - 解释产物不替代当前事实文档、流程契约或可执行证据。
- 审查摘要按需要说明变化、理由、证据、未验证项与待决定事项，不强制固定字段。

## 交互 HTML

本节规定交互解释的最小交付与复核要求；交互用于说明条件变化的结果。

- 单文件使用原生 CSS、JavaScript 与 inline SVG，不依赖外部运行资源。
- 控件提供标签、键盘操作与可见 focus；文字和图形支持桌面与窄屏阅读。
- 示例前提与未核实项在页面可见；模拟结果不得表述为真实执行或通过证据。
- 生成后打开页面，核对来源、操作控件并检查桌面与窄屏渲染，再修复发现的问题。
  - 无法检查的部分如实记录；页面可操作不等于真实系统行为已验证。
- 交付 HTML、打开方式与来源；仅在用户要求时发布，不隐式执行页面所解释的命令。
