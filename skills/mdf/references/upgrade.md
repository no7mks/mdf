# Upgrade

`$mdf upgrade` 从上游 Git 默认分支拉取最新 MDF Skill，替换当前仓库中已安装的
`mdf` 副本，并更新已有 `AGENTS.md` 的 MDF 托管区块。不修改 `.mdf/`、`docs/`
或业务文件，不覆盖源仓库的 `skills/mdf`。

## 决策树

```text
┌──────────────────────────────────┐

                 │

```

## 工作流（唯一执行契约）

表中操作与证据按下方同名条目核对；顺序与跳转只由本表规定。

不读取 `references/common.md`。本 intent 替换已安装 Skill，并更新已有
`AGENTS.md` 托管区块；不按文档归属选择分支，不自动提交。

| # | 步骤 | 类型 | 做什么 | 证据 | 通过 → | 失败/缺失 → |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 工具 | 脚本 | 运行 `info`，解析 Git 根 | 版本 2、REPO_ROOT | 2 | 停止 |
| 2 | 预览 | 脚本 | dry-run 拉取并列出替换目标与 AGENTS 区块 | 旧/新基线、目标、区块计划 | 3 | 停止 |
| 3 | 确认 | 约束 | 展示计划并取得明确替换确认 | 用户确认 | 4 | 拒绝则结束 |
| 4 | 替换 | 脚本 | 非预览写入已安装 Skill 与已有 AGENTS 托管区块 | 新 `.version`、目录、区块 | 5 | 保留现场，停止 |
| 5 | 报告 | 约束 | 报告新旧基线、路径与 AGENTS 区块结果，不提交 | 结果摘要 | 结束 | 停止 |

## 术语与数据结构

### 工具与预览

<a id="s1"></a>

**工具**

解析 `REPO_ROOT`。运行
`python3 "$MDF_ROOT/scripts/mdf.py" info`，协议、工具与 schema 版本均须为
数字 `2`。不要求 manifest、ready 或 clean worktree。

验收：Git 根、三个版本为 2。

通过条件：进入预览。异常与交接：停止，不得模拟 CLI。

<a id="s2"></a>

**预览**

默认源为 `http://10.1.5.65:8929/mars/mdf`，取远程默认分支 HEAD。仅当用户给出
其他源时传 `--source`。

```bash
upgrade --repo "$REPO_ROOT" --dry-run
```

有 `--source` 时追加 `--source <url>`。CLI 只扫描已存在的 Agent Skills 目录中的
`mdf`，不创建未安装位置，不触碰 `skills/mdf`。输出须含 `source`、`new_commit`、
`targets`、`agents` 与每项目标的当前基线。无安装目标或拉取失败时停止。
有唯一托管区块时报告将更新或已相同；无 `AGENTS.md` 或无区块则 `skip`。
标记错误或重复时停止。

验收：结构化预览、至少一个目标。

通过条件：进入确认。异常与交接：不写入。

### 确认与替换

<a id="s3"></a>

**确认**

向用户展示源、新 commit、将替换的路径、当前 `.version` 和 `AGENTS.md` 区块计划。
说明已安装 Skill 的本地改动会丢失；已有托管区块会被上游模板替换，非托管内容
保留；不改 `.mdf/` 与 `docs/`。必须取得明确替换确认；拒绝则结束且不写入。
不得把沉默当作同意。

验收：用户明确确认或明确拒绝。

通过条件：确认后进入替换。异常与交接：拒绝则结束。

<a id="s4"></a>

**替换**

```bash
upgrade --repo "$REPO_ROOT"
```

预览用过 `--source` 时这里使用同一源。CLI 用上游 `skills/mdf` 替换每个已安装
副本，并写入完整 commit 到 `references/.version`。已有唯一 `AGENTS.md` 托管
区块时，用上游 `agents-managed-block.md` 替换该区块；无文件或无区块则跳过，
不新建或追加。失败时保留现场，报告已替换与未替换路径。不得删除目标仓库的
`.mdf/` 或 `docs/`。

验收：各目标目录存在、`.version` 等于 `new_commit`，`agents` 结果已落实。

通过条件：进入报告。异常与交接：保留现场并停止。

<a id="s5"></a>

**报告**

报告旧基线、新基线、替换路径和 `AGENTS.md` 区块结果。不提交。提示在新会话使用
更新后的 Skill。

验收：结果摘要与 CLI 产物一致。

通过条件：结束。异常与交接：停止。
