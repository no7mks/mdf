## 术语与数据结构

### 执行约束

下列明细补充表中操作、证据与异常处理；步骤顺序和跳转只由上表规定。

<a id="s1"></a>

**入口**

解析 `REPO_ROOT` 并运行 `doctor`。

验收：`normal_workflows_allowed: true`。

异常与交接：manifest 未就绪时提示 `$mdf init`，其他 findings 报告后停止。

<a id="s2"></a>

**盘点**

按可选`方向`盘点 `README.md`、`PROJECT.md`、`JOTS.md`、 `manifest`
、当前事实文档、实现根、测试、active Proposal/Bug、fulfilled Proposal 与 unreleased Change；
追踪候选项所需的仓库证据，但不执行 `audit` 或验证命令， 也不得把盘点称为审阅。

验收：已读范围、未触及范围及理由。

异常与交接：报告缺失材料并停止。

<a id="s3"></a>

**候选**

结合仓库证据与用户目标展示少量候选下一步；
每项说明 Problem、目标用户或受益方、最小可验证结果、 明确排除范围、已有对象重叠及选择理由；
仓库证据不能决定产品优先级时询问用户。

验收：候选项与取舍。

异常与交接：仓库事实不足时回到 2；目标或优先级不明时留在 3 询问用户。

<a id="s4"></a>

**选择**

一次只选择一个 MVP，且必须是最小但可验证、可交付的结果，不得只是技术任务清单。

验收：用户明确确认该 MVP、目标与边界。

异常与交接：回到 3。

<a id="s5"></a>

**澄清**

以确认的 MVP 和仓库证据为议题，使用内部 clarify intent；
收敛 Problem、 Desired Outcome、Scope、验收方式、 关键取舍、约束与排除范围，并取得 clarify 要求的共同理解确认。

验收：已解决的决策树。

异常与交接：不写入任何对象并停止。

<a id="s6"></a>

**拆分**

按独立评审与验证边界拆成最少数量的一个或多个 Proposal，不得为制造数量而拆分；每项都满足 Proposal 必填事实。
`depends_on` 只记录直接依赖并形成无环 DAG；fulfilled 依赖视为已满足，其余节点按拓扑批次展示推荐落地顺序，
同一批可并行； DAG 与批次均为从 `depends_on` 动态计算的会话视图，不写入字段或独立文件。

验收：PRP 清单、边界、DAG 与批次。

异常与交接：回到 5。

<a id="s7"></a>

**复用**

检查 active/fulfilled Proposal 的重叠与复用；已有对象可作为清单项或新 Proposal 的直接依赖，
但不得由本 intent 修改。需要改变已有对象范围时停止， 要求先显式调用 `$mdf prp review`；
active Bug 只作为风险或阻塞项展示，不写入 `depends_on`；其他终态 Proposal 不得作为依赖。

验收：复用、重复、风险与阻塞判断。

<a id="s8"></a>

**确认**

展示每项 Problem、Desired Outcome、In/Out、Acceptance Criteria、 直接依赖、拓扑批次及现有/新建标记。

验收：只有用户明确确认清单才继续。

异常与交接：MVP 的目标、范围或验收变化时回到 5；仅拆分或依赖变化时回到 6； 不写入任何对象。

<a id="s9"></a>

**创建**

为每个新 Proposal 提议并确认英文 ASCII kebab-case slug，逐项使用 `make-id --type proposal --slug`
生成全部 ID 与规范化文件名，再以 Proposal 模板写入 `proposals/`；只用 `depends_on` 填入新旧直接依赖，
不写入批次， 初始状态为 `draft`。

验收：全部 draft。

异常与交接：停止并保留现场。

<a id="s10"></a>

**校验**

所有 draft 写入后运行 `targeted validation`。

验收：零 finding。

异常与交接：保留 draft 和现场并报告 findings，不得宣称产出可落地。

<a id="s11"></a>

**报告**

展示新建与复用 PRP、依赖 DAG、拓扑批次、风险、排除范围和 validation 结果。

验收：会话摘要。

异常与交接：停止。新建对象保持 `draft`，后续逐项显式调用 `$mdf prp review` 转为 `ready`；不得自动 commit。
